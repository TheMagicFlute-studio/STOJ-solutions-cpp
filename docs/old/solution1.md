# 老OJ #1 A+B问题

## 基础解法 by [TheMagicFlute](https://github.com/TheMagicFlute)

### 主要算法

标准输入输出流 `cin` `cout`。

### 思路

读入两个整数，输出它们的和。

### 代码

```cpp
#include <iostream>

using namespace std;

int main(int argc, char *argv[])
{
    int a, b;
    cin >> a >> b;
    cout << a + b << endl;

    return 0;
}

```

### 结语

注意输入输出流符号的方向，不要搞混！
